# ElderCare Companion — Frontend

This is the frontend-only stage of the ElderCare Companion full-stack college project.

## Included pages

- Home
- About
- Services
- Contact
- Login
- Register
- Dashboard
- Medicine Reminder
- Doctor Appointments
- Health Records
- Emergency SOS

## Current behavior

The frontend works without a backend by using browser `localStorage` for demo data.

This is intentional. In the next stage, the localStorage operations will be replaced with REST API calls to the Spring Boot + MongoDB backend.

## Run

Open `index.html` with VS Code Live Server, or open it directly in a browser.

## Next backend integration

The planned API modules are:

- `/api/users`
- `/api/medicines`
- `/api/appointments`
- `/api/health-records`
- `/api/emergency-contacts`

Do not store real medical information in this student demo.
